The answer names what a write to the `{ get set }` requirement `setting4_2` generates besides
`setting4_2SetCount`: `setting4_2SetArgs`, holding each value written, and `setting4_2SetHandler`,
which receives it.

It fails if it omits `setting4_2SetArgs` or `setting4_2SetHandler`, or if it gives either member to
the read-only `pageSize`.
